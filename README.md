# KΛZX-light-card

Une carte interactive qui s'allume : la lumière épouse la forme de la carte et révèle les détails.

## Fonctionnalités

- Bouton d'alimentation animé pour allumer / éteindre
- 5 couleurs de lumière au choix (blanc, ambre, cyan, violet, rose)
- Effet 3D qui suit la souris
- Sons générés avec la Web Audio API (aucun fichier audio)
- Accessible au clavier (Entrée ou Espace sur la carte)
- Respecte `prefers-reduced-motion`

## Utilisation

Aucune installation nécessaire : ouvre simplement `index.html` dans ton navigateur.

## Structure

```
index.html   page principale
style.css    styles et effets de lumière
script.js    interactions et sons
```
